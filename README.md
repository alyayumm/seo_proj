# task-SEO

Статический трекер задач для GitHub Pages: проекты, ответственные, хронология, календарь плана/факта, общий дашборд, отчет по закупу ссылок из Google Sheets и планы работ по клиентам из Google Docs/Sheets.

Первый релиз сохраняет задачи в браузере через `localStorage`. Закуп ссылок читается автоматически из вкладки `План` таблицы `Закупка ссылок SEO — сводная` через публичный GViz endpoint. Планы работ пока привязаны как проверенные источники по проектам. Для общей командной базы задач следующим этапом можно подключить Google Sheets, Supabase или Firebase.

## Команды

```bash
npm install
npm run dev
npm run build
```
