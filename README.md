# task-SEO

Статический трекер задач для GitHub Pages: проекты, ответственные, хронология, календарь плана/факта и общий дашборд.

Первый релиз сохраняет данные в браузере через `localStorage`. Для общей командной базы следующим этапом можно подключить Google Sheets, Supabase или Firebase.

## Команды

```bash
npm install
npm run dev
npm run build
```
