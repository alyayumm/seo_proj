# task-SEO

Статический трекер задач для GitHub Pages: проекты, ответственные, хронология, календарь плана/факта, общий дашборд и отчет по закупу ссылок из Google Sheets.

Первый релиз сохраняет задачи в браузере через `localStorage`. Закуп ссылок читается автоматически из вкладки `План` таблицы `Закупка ссылок SEO — сводная` через публичный CSV/GViz endpoint. Для общей командной базы задач следующим этапом можно подключить Google Sheets, Supabase или Firebase.

## Команды

```bash
npm install
npm run dev
npm run build
```
